# Assembly image provenance

Files `01` through `06` are downscaled copies of photographs taken by project owner `bouyous` on 11 July 2026. They were resized and recompressed for web use; no generative editing, component replacement or pin alteration was applied.

Files `08` and `09` are crops of a screenshot supplied by the project owner from Seeed Studio's official [XIAO ESP32-S3 and Wio-SX1262 product documentation](https://wiki.seeedstudio.com/wio_sx1262_with_xiao_esp32s3_kit/). File `09` isolates the battery-pad portion for readability.

`assembly-tutorial-source.html` is the deterministic bilingual layout source. The French and English tutorial PNGs are browser renders of that file. All labels remain editable text in the source rather than generated text embedded by an image model.
